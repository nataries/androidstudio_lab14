# Лабораторная работа №13-14. ViewModel и архитектура Android-приложений

##  Краткое описание игры

Scrumble - давно известная игра, суть которой заключается в том, что есть заранее подготовленный список слов. Пользователю поочередно выдаются слова из этого списка, только буквы в этих словах перемешаны. Задача игрока - восстановить первозданный вид слова: за правильный ответ на счёт игрока начисляются очки, за неправильный ничего не добавляется и не убавляется. Игра продолжается, пока слова из списка не закончатся.

## Функциональность приложения
+ В приложении заранее создан список слов по тематике, связанной с Android Studio, из которого последовательно выдаются слова
+ Реализована возможность поворота телефона с ViewModel
+ Увеличение количества очков при правильном ответе игрока
+ Возможность проверки правильности введённого пользователем слова и вывод сообщения, если слово неверно
+ Завершение игры с диалогом, на котором указан счет и кнопка "Играть снова". При нажатии на кнопку счет обнуляется, и игра начинается заново

## Контрольные вопросы

1. Что такое ViewModel и зачем он нужен?

View Model хранит данные UI отдельно от Composable-функций. Также его отличительная особенность заключается в том, что при повороте экрана телефона данные не теряются, а заново восстанавливаются на экране.
